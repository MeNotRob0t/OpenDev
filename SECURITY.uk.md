# Безпека

## ВАЖЛИВО

Ми не приймаємо звіти про безпеку, згенеровані ШІ. Ми отримуємо їх велику кількість і абсолютно не маємо ресурсів, щоб перевірити їх усі. Якщо ви надішлете один, це буде автоматичним баном від проекту.

## Модель Загроз

### Огляд

OpenCode — це помічник з кодування на основі ШІ, який працює локально на вашому комп'ютері. Він надає систему агентів з доступом до потужних інструментів, включаючи виконання оболонки, операції з файлами та веб-доступ.

### Немає Песочниці (Sandbox)

OpenCode **не** ізолює агента в песочниці. Система дозволів існує як функція UX, щоб допомогти користувачам усвідомлювати дії, які вчиняє агент — він запитує підтвердження перед виконанням команд, записом файлів тощо. Проте він не призначений для надання ізоляції безпеки.

Якщо вам потрібна справжня ізоляція, запустіть OpenCode всередині Docker-контейнера або віртуальної машини.

### Режим Сервера

Режим сервера доступний лише за підпискою (opt-in). При увімкненні встановіть `OPENCODE_SERVER_PASSWORD` для вимоги HTTP Basic Auth. Без цього сервер працює без автентифікації (з попередженням). Забезпечення безпеки сервера — відповідальність кінцевого користувача; будь-яка функціональність, яку він надає, не є вразливістю.

### Поза Межами

| Категорія | Обґрунтування |
| ------------------------------- | ----------------------------------------------------------------------- |
| **Доступ до сервера при opt-in** | Якщо ви увімкнете режим сервера, доступ до API — очікувана поведінка |
| **Втечі з песочниці** | Система дозволів не є песочницею (див. вище) |
| **Обробка даних постачальника LLM** | Дані, надіслані вашому налаштованому постачальнику LLM, регулюються їхніми політикими |
| **Поведінка сервера MCP** | Зовнішні сервери MCP, які ви налаштували, знаходяться за межами нашої межі довіри |
| **Зловмисні файли конфігурації** | Користувачі контролюють власну конфігурацію; її зміна не є вектором атаки |

# Повідомлення про Проблеми Безпеки

Ми цінуємо ваші зусилля щодо відповідального розкриття ваших висновків і зробімо всі можливі зусилля для визнання вашого внеску.

Щоб повідомити про проблему безпеки, будь ласка, використайте вкладку GitHub Security Advisory ["Report a Vulnerability"](https://github.com/anomalyco/opencode/security/advisories/new).

Команда надішле відповідь, що вказує на наступні кроки у обробці вашого звіту. Після першої відповіді на ваш звіт команда безпеки буде тримати вас в курсі прогресу щодо виправлення та повного оголошення, і може запитати додаткову інформацію або вказівки.

## Ескалація

Якщо ви не отримали підтвердження вашого звіту протягом 6 робочих днів, ви можете надіслати електронного листа на security@anoma.ly
