# Безопасность

## ВАЖНО

Мы не принимаем отчеты о безопасности, сгенерированные ИИ. Мы получаем их большое количество и абсолютно не имеем ресурсов для их проверки. Если вы отправите такой отчет, это приведет к автоматическому исключению из проекта.

## Модель Угроз

### Обзор

OpenCode — это ИИ-помощник по программированию, который запускается локально на вашем компьютере. Он предоставляет систему агентов с доступом к мощным инструментам, включая выполнение оболочки, операции с файлами и веб-доступ.

### Нет Песочницы (Sandbox)

OpenCode **не** изолирует агента в песочнице. Система разрешений существует как функция UX, чтобы помочь пользователям оставаться в курсе действий агента — она запрашивает подтверждение перед выполнением команд, записью файлов и т.д. Однако она не предназначена для обеспечения безопасности через изоляцию.

Если вам нужна настоящая изоляция, запустите OpenCode внутри Docker-контейнера или виртуальной машины.

### Режим Сервера

Режим сервера доступен только по выбору (opt-in). При включении установите `OPENCODE_SERVER_PASSWORD` для требования HTTP Basic Auth. Без этого сервер работает без аутентификации (с предупреждением). Обеспечение безопасности сервера — ответственность конечного пользователя; любая предоставляемая функциональность не является уязвимостью.

### Вне Области Применения

| Категория | Обоснование |
| ------------------------------- | ----------------------------------------------------------------------- |
| **Доступ к серверу при opt-in** | Если вы включите режим сервера, доступ к API — ожидаемое поведение |
| **Побег из песочницы** | Система разрешений не является песочницей (см. выше) |
| **Обработка данных провайдером LLM** | Данные, отправленные вашему настроенному провайдеру LLM, регулируются их политиками |
| **Поведение сервера MCP** | Внешние серверы MCP, которые вы настраиваете, находятся за пределами нашей границы доверия |
| **Вредоносные файлы конфигурации** | Пользователи контролируют свою конфигурацию; её изменение не является вектором атаки |

# Сообщение о Проблемах Безопасности

Мы ценя ваши усилия по ответственному раскрыванию ваших находок и применим все усилия для признания вашего вклада.

Чтобы сообщить о проблеме безопасности, используйте вкладку GitHub Security Advisory ["Report a Vulnerability"](https://github.com/anomalyco/opencode/security/advisories/new).

Команда отправит ответ с указанием следующих шагов по обработке вашего отчета. После первоначального ответа на ваш отчет команда безопасности будет держать вас в курсе прогресса к исправлению и полному объявлению, и может запросить дополнительную информацию или руководство.

## Эскалация

Если вы не получите подтверждение вашего отчета в течение 6 рабочих дней, вы можете отправить электронное письмо на security@anoma.ly
