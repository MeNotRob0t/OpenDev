### ما هو OpenDev؟

OpenDev هو متغير شخصي لـ OpenCode، وهو وكيل ترميز بالذكاء الاصطناعي مفتوح المصدر يعمل في
الطرفية لديك. يعتمد على كود OpenCode مع تعديلات محلية وتكوين معدل
 ليناسب طريقة عملي.

للحصول على مجموعة الميزات الكاملة للمشروع الأصلي، والوثائق، والمجتمع، راجع
[**OpenCode**](https://github.com/anomalyco/opencode) ووثائقه في [**opencode.ai**](https://opencode.ai/docs).

### التثبيت

يعمل OpenDev من الكود المصدري باستخدام [Bun](https://bun.sh).

```bash
# تثبيت التبعيات
bun install

# تشغيل خادم التطوير
bun dev

# إذا أردت، يمكنك بناؤه أيضًا

bun build ./src/index.ts --compile --outfile ./dist/OpenDev.exe
```

للتثبيتات الثنائية للمشروع الأصلي (OpenCode غير المعدل)، راجع
[المثبت الرسمي](https://opencode.ai/install).

### الوثائق

يتم تكوين OpenDev بنفس طريقة OpenCode. لمعرفة كيفية تكوين OpenCode، توجه إلى وثائق المشروع الأصلي في
[**opencode.ai/docs**](https://opencode.ai/docs).
