### Co to jest OpenDev?

OpenDev to osobisty wariant OpenCode, open source agenta AI do kodowania, który działa w Twoim
terminalu. Buduje na bazie kodu OpenCode z lokalnymi modyfikacjami i konfiguracją dopasowaną
do mojego sposobu pracy.

Pełny zestaw funkcji upstream, dokumentację i społeczność znajdziesz w
[**OpenCode**](https://github.com/anomalyco/opencode) oraz jego docsach na [**opencode.ai**](https://opencode.ai/docs).

### Instalacja

OpenDev uruchamia się z kodu źródłowego z [Bun](https://bun.sh).

```bash
# Zainstaluj zależności
bun install

# Uruchom serwer deweloperski
bun dev

#jeśli chcesz, możesz to też zbudować

bun build ./src/index.ts --compile --outfile ./dist/OpenDev.exe
```

Dla upstreamowych instalacji binarnych (niemodyfikowany OpenCode), zobacz
[oficjalny installer](https://opencode.ai/install).

### Dokumentacja

OpenDev jest konfigurowany tak samo jak OpenCode. Aby dowiedzieć się, jak konfigurowany jest OpenCode, przejdź do upstreamowych docsów na
[**opencode.ai/docs**](https://opencode.ai/docs).
