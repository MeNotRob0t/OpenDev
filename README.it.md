### Cos'è OpenDev?

OpenDev è una variante personale di OpenCode, un agente di codifica AI open source che gira nel tuo
terminale. Si basa sulla codebase di OpenCode con modifiche locali e configurazione ottimizzata
per il mio modo di lavorare.

Per il set completo di funzionalità upstream, documentazione e community, vedi
[**OpenCode**](https://github.com/anomalyco/opencode) e i suoi docs su [**opencode.ai**](https://opencode.ai/docs).

### Installazione

OpenDev gira dal sorgente con [Bun](https://bun.sh).

```bash
# Installa dipendenze
bun install

# Avvia il server di sviluppo
bun dev

#se vuoi, puoi anche buildarlo

bun build ./src/index.ts --compile --outfile ./dist/OpenDev.exe
```

Per installazioni binarie upstream (OpenCode non modificato), vedi l'
[installer ufficiale](https://opencode.ai/install).

### Documentazione

OpenDev è configurato nello stesso modo di OpenCode. Per come è configurato OpenCode, vai ai docs upstream su
[**opencode.ai/docs**](https://opencode.ai/docs).
