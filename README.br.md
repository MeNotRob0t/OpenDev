### Apa Iku OpenDev?

OpenDev varian pribadi saka OpenCode, open source AI coding agent sing lumaku ing
terminal sampeyan. Iku dibangunake kanthi codebase OpenCode kanthi owah-owahan lokal lan konfigurasi sing di-tune
kanggo cara aku kerja.

Kanggo full upstream feature set, dokumentasi, lan komunitas, deleng
[**OpenCode**](https://github.com/anomalyco/opencode) lan docs-é ing [**opencode.ai**](https://opencode.ai/docs).

### Instalasi

OpenDev lumaku saka source kanthi [Bun](https://bun.sh).

```bash
# Instal dependensi
bun install

# Jaluk dev server
bun dev

# yen sampeyan pengin, sampeyan uga bisa build

bun build ./src/index.ts --compile --outfile ./dist/OpenDev.exe
```

Kanggo upstream binary instals (OpenCode tanpa owah-owahan), deleng
[instaler resmi](https://opencode.ai/install).

### Dokumentasi

OpenDev dikonfigurasi padha karo OpenCode. Kanggo ndeleng cara OpenCode dikonfigurasi, mlebu docs upstream ing
[**opencode.ai/docs**](https://opencode.ai/docs).
