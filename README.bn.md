### OpenDev কী?

OpenDev হল OpenCode-এর একটি ব্যক্তিগত biến thể, একটি ওপেন সোর্স AI কোডিং এজেন্ট যা আপনার
টার্মিনালে চলে। এটি স্থানীয় পরিবর্তন ও কনফিগারেশন সহ OpenCode কোডবেসের ওপর বিল্ট
আমার কাজের শৈলী অনুযায়ী টিউন্ড।

সম্পূর্ণ আপস্ট্রিম ফিচার সেট, ডকুমেন্টেশন ও কমিউনিটির জন্য দেখুন
[**OpenCode**](https://github.com/anomalyco/opencode) এবং এর ডক্স [**opencode.ai**](https://opencode.ai/docs)-এ।

### ইনস্টলেশন

OpenDev [Bun](https://bun.sh)-এর সাথে সোর্স থেকে চলে।

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
bun install

# ডেভ সার্ভার চালান
bun dev

# যদি চান, তাহলে এটি বিল্ডও করতে পারেন

bun build ./src/index.ts --compile --outfile ./dist/OpenDev.exe
```

আপস্ট্রিম বাইনারি ইনস্টলের জন্য (আনমডিফাইড OpenCode), দেখুন
[অফিসিয়াল ইনস্টলার](https://opencode.ai/install)।

### ডকুমেন্টেশন

OpenDev কনফিগার করা হয় OpenCode-এর মতোই। OpenCode কীভাবে কনফিগার করা হয় তা জানতে আপস্ট্রিম ডক্সে যান
[**opencode.ai/docs**](https://opencode.ai/docs)।
